# 🍰 Telegram-бот «ВКУСНО И ПРИЯТНО»

Бот для продажи сладостей с сайта. Каталог, корзина и оформление заказа —
все товары и цены взяты из `index.html`.

## Возможности

- 🍰 **Каталог** — все 6 сладостей с ценами и описаниями
- 🛒 **Корзина** — кнопки ➕ / ➖ / 🗑, автоматический пересчёт суммы
- ✅ **Оформление заказа** — имя и номер телефона (кнопкой «Отправить номер»)
- 📦 **Заказы** — приходят вам в личный чат + сохраняются в `bot/orders.json`
- 💾 Корзины клиентов сохраняются между перезапусками (`bot/carts.json`)

## Настройка

1. Получите токен у [@BotFather](https://t.me/BotFather) → `/newbot`
2. Узнайте свой ID у [@userinfobot](https://t.me/userinfobot)
3. Создайте файл `.env` в корне проекта (образец в `.env.example`):

```
BOT_TOKEN=123456:ABC-your-token-here
ADMIN_CHAT_ID=123456789
```

## Запуск

```bash
npm run bot
```

Бот работает офлайн (long polling) — хостинг и HTTPS не нужны, достаточно Node.js 18+.

## Команды

| Команда   | Что делает              |
|-----------|-------------------------|
| /start    | Меню                    |
| /catalog  | Каталог сладостей       |
| /cart     | Корзина                 |
| /orders   | Последние заказы (только для вас) |
| /cancel   | Отменить оформление заказа |
